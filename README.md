# Upbuild Contract Automation — Web App

A simple web form that generates a coaching agreement `.docx` and emails it to you.

## How it works

1. Someone opens the URL and fills in: client name, client email, coach, and session rate.
2. The app generates a `.docx` agreement from the template.
3. You receive an email at `michael@upbuild.com` with:
   - The client's email address (for your follow-up)
   - The agreement attached as a `.docx`

---

## Local development

```bash
# Install dependencies
pip install -r requirements.txt

# Add credentials to .env
echo "GMAIL_USER=ea.michael108@gmail.com" >> .env
echo "GMAIL_PASSWORD=your-16-char-app-password" >> .env
echo "NOTIFY_EMAIL=michael@upbuild.com" >> .env

# Run
python3 app.py
# Open http://localhost:5000
```

## Deploy to Render (free tier)

### 1. Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit"
# Create a repo on github.com, then:
git remote add origin https://github.com/YOUR_USERNAME/upbuild-contracts.git
git push -u origin main
```

> **Note:** `Dummy Agreement.docx` is included as a placeholder template.  
> Replace it with your real agreement before deploying.

### 2. Create a Render account

Go to [render.com](https://render.com) → sign up → **New > Web Service** → connect your GitHub repo.

Render will auto-detect `render.yaml` and configure the service.

### 3. Set environment variables in Render

In your Render service → **Environment** tab, add:

| Key | Value |
|-----|-------|
| `GMAIL_USER` | `ea.michael108@gmail.com` |
| `GMAIL_PASSWORD` | your 16-char Gmail App Password |
| `NOTIFY_EMAIL` | `michael@upbuild.com` |

`SECRET_KEY` is auto-generated by `render.yaml`.

### 4. Deploy

Render deploys automatically on every `git push`. Your public URL will be something like:  
`https://upbuild-contract-automation.onrender.com`

## Swapping in the real template

Replace `Dummy Agreement.docx` with your actual template.  
The template must contain these exact placeholder strings:

| Placeholder | Replaced with |
|-------------|---------------|
| `Alexis Gevorgian` | Client full name |
| `Alexis` | Client first name |
| `Rasanath Das` | Selected coach |
| `$600` | Session rate |

## Gmail App Password setup

1. Enable 2-Step Verification on the Gmail account.
2. Go to **myaccount.google.com → Security → App Passwords**.
3. Create a new App Password (select "Mail" / "Other").
4. Use the 16-character password (no spaces) as `GMAIL_PASSWORD`.
